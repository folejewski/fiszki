# Fiszki

A mobile-first flashcard app for learning European Portuguese in Polish, built with React, TypeScript and Supabase.

Work in progress - [live demo](https://fiszki-sable.vercel.app)

## Run locally

```
npm install
npm run dev
```

## Tests

```
npm run test:run
```
